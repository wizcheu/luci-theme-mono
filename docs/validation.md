## 设备验收建议

安装后依次打开状态概览、网络接口、系统设置和 OpenClash 配置页，检查菜单权限与页面控件。使用一个可恢复的普通系统设置验证保存 / 应用，然后验证重新登录与原主题恢复。保留现有 Argon 或 Bootstrap 作为备用主题。
